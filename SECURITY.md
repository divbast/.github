# Security policy

Report a vulnerability privately through the affected repository: open
its **Security** tab and choose **Report a vulnerability**. Every divbast
repository accepts private reports. Please don't open a public issue for
a security problem.

A problem in an app itself (Baikal, for example) belongs with that app's
own project. Report it here when it is about what divbast adds: the
image, its confinement, its build or its publishing.

Only the newest published image of each app is supported: fixes ship in
the next daily publish, never as a backport to an older tag.
